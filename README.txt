الحاجة | Al Haaja — موقع متكامل (HTML + CSS + Bootstrap + JS)

افتح:  home/index.html   (أو index.html في الجذر)

الهيكل: كل صفحة في فولدر مستقل فيه (index.html + css + js) وكلهم مربوطين بملفات مشتركة في assets/
  assets/css/main.css   الهوية البصرية المشتركة (بنفسجي / بني / ذهبي)
  assets/js/data.js     <<< عدّل من هنا: رقم الواتساب، العنوان، الأسعار، المنتجات، عدد الترابيزات
  assets/js/main.js     النافبار، الفوتر، اللودنج، العربة
  assets/img/           الصور (استبدلها بصورك بنفس الأسماء أو غيّر المسارات في data.js)

أهم إعداد: في assets/js/data.js غيّر whatsapp: "201000000000" إلى رقمك (بصيغة دولية بدون +).
كود QR للترابيزات: اجعل رابط الترابيزة رقم 5 مثلًا  menu/index.html?table=5
Bootstrap والخطوط والأيقونات بتتحمل من CDN (محتاج إنترنت وقت التشغيل).
